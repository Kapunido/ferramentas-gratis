# Ferramentas Grátis — versão profissional

## O que foi incluído
- Página inicial profissional.
- 30 ferramentas.
- Uma página HTML individual para cada ferramenta, facilitando SEO.
- Busca de ferramentas na página inicial.
- Páginas Sobre, Contato, Privacidade e Termos.
- `robots.txt` e `sitemap.xml`.
- Layout responsivo para celular e PC.
- Espaços preparados para publicidade.
- Estrutura sem servidor: pode ser hospedada gratuitamente.

## Antes de publicar
1. Abra `contato.html` e troque `braboleta117@gmail.com` pelo seu e-mail.
2. Em `robots.txt` e `sitemap.xml`, troque `kapunido` pelo seu usuário do GitHub e confirme o nome do repositório.
3. Se usar outro domínio, troque as URLs canônicas das páginas.
4. Revise a política de privacidade/termos conforme os serviços que você realmente instalar.

## Publicação gratuita no GitHub Pages
Crie um repositório público, envie todos os arquivos desta pasta, depois abra Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Monetização
Depois de o site estar publicado e com conteúdo/uso reais, você pode solicitar uma plataforma de publicidade como o Google AdSense. A aprovação e a receita não são garantidas. Nunca coloque código de anúncio de outra pessoa nem clique nos próprios anúncios.

## Observação
As páginas de política e termos são modelos gerais e não substituem revisão jurídica.
